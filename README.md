## 一、它是什么

脚本里「5号选手」的设定是：**AI 编程助手 + 智能运维工程师**，两个职责都很具体：

| 脚本原话 | 本实现里的落地 |
|---|---|
| 「我根据同事们的需求起草代码，经授权，直接交付到他们指定的文件夹」 | 收到指令 → 生成代码 → 真写进 `交付/<任务>/` |
| 「同时在 Git 仓库留痕」 | 在 `交付/` 独立仓库自动 `git commit`，可 `git log` 查 |
| 「同事们负责审查和优化」 | 代码带完整注释与参数外置，交付说明里写明请审查 |
| 「上线之后，我还负责监测模型的检测效率」 | 每 30s 巡检真实检测库，置信度漂移超阈值就报警 |

**形象**默认是 **2.5D 照片数字人**（`avatar/assets/portrait.png`）：整张人像做成一整块
细分平面（160×160 网格），在**顶点着色器里做局部 UV 变形**实现张嘴 / 眨眼，
所以没有拼接缝、也最像真人照片。带呼吸浮动、边缘渐隐。
另保留 3D 模式：Rocketbox 写实男性（FBX，带 15 个 Oculus viseme）与任意 VRM，
用 `?model=` 切换。
**声音**是 edge-tts 预渲染成 19 个 mp3（男声 `zh-CN-YunxiNeural`），现场只播文件，断网不影响。

## 六、离线是默认，不是退路

比赛现场最大的风险是网络。所以：

- **语音**：全部预渲染成 mp3，现场只读本地文件
- **理解**：默认走离线意图引擎，靠正则匹配剧本里的真实意图，不依赖任何 API
- **渲染**：three.js 全部打进 `dist/avatar.bundle.js`（721 KB），不连 CDN
- **数据**：直接读本地 sqlite

想让它在自由问答上更聪明，把 DeepSeek key 填进 `config/llm.json` 的 `api_key`（或设环境变量 `DEEPSEEK_API_KEY`）。有 key 走真 LLM + function calling，**失败会自动降级回离线引擎**，不会哑在台上。

## 八·五、语音交互 + 真 GPU 调度 + 身边的运维屏（2026-11-13 新增）

一句话：**说话能听懂 → 真的把 GPU 转起来干活 → 干完自己停 → 身边那块屏上能看见模型性能趋势。**

### 怎么起

```bat
启动数字人_语音版.bat
```

它比老脚本多做两件事：先起 `asr_service.py`（8773，voice 环境，模型常驻），
再多开一个窗口 `avatar/ops.html`（运维屏，拖到形象窗口右边即可）。

### 链路（每一段都实测过）

| 环节 | 实现 | 实测数字 |
|---|---|---|
| 采集 | 浏览器 WebAudio → 前端重采样成 16k 单声道 WAV | **常听默认开**：VAD 断句（静音 0.8s）自动送识别；说满 15s 强制切；阈值为自适应底噪 floor×2.2；回复播放期间不采（防自听）；5s 看门狗自动接回采集 |
| 识别 | `asr_service.py`（FunASR Paraformer-zh + fsmn-vad + ct-punc，CPU） | 模型热身 **29.9s**（模型已缓存）；单句 **0.33s**（3.07s 音频，RTF 0.11） |
| 理解 | `agent.py`：有 key 走 DeepSeek function-calling，没 key 走离线意图引擎 | 两条通道都接得住「让 GPU 跑一下训练」 |
| 动手 | `gpu_runner.py` 起 `gpu_worker.py`（yoloces 环境，CUDA） | 真训练：2 轮 / 248 张 / imgsz 320 / **68.8s**，GPU 利用率 27~30%、显存 5.7GB、68℃ |
| 自己停 | worker 跑完即退，父进程只读 `progress.jsonl` | 作业结束 `exit_code=0`，GPU 回到 6% / 2.1GB |
| 回话 | `tts.py`：SAPI 离线合成（`Microsoft Huihui`），可选 edge-tts | 单句 **~0.7s** 出声，断网可用 |
| 看板 | `avatar/ops.html` 轮 `/api/ops`（2s） | GPU 利用率/显存/温度曲线 + 自学习 mAP50 序列 + 会话置信度 + 作业进度 |

### 三条必须知道的工程坑（都踩过并修了）

1. **中文路径不能进命令行**。Windows 会把 `F:\木材缺陷数据集…` 传给子进程时变成乱码，
   ultralytics 直接报「images not found」。所以建了三个 ASCII 软链：
   `C:\dh_root`→数字人、`C:\dh_prod`→new mcjc、`C:\dh_ds`→F:\木材缺陷数据集6类3000+，
   所有传给子进程的路径都走软链。
2. **数据集自带的 wood.yaml 是作者机器上的 Linux 绝对路径**，不能用；
   worker 每次按 `C:/dh_ds` 现生成一份 data.yaml。
3. **ultralytics 的 AMP 自检会去外网下 yolo26n.pt**，断网现场会卡死；已设 `amp=False`。

### 边界（红线照旧）

- 训练只读产线权重 `models/yolo26m.pt` 与数据集，权重只落在 `数字人/ops_jobs/<作业>/runs/`。
  **`models/yolo26m_wood_best.pt` 的 mtime 仍是 2026-10-24 16:46，没动过。**
- 数据库全程 `mode=ro`，只读不写。
- GPU 作业同一时刻只允许一个：正在跑时再喊「训练」，会回「上一个还没完」，不重复起。

### 它是怎么「一直听着」的

1. **一次授权，之后一直听**：页面打开后随便点一下（浏览器规定必须有用户动作才给麦克风），
   之后就进入常听状态，不用再按键。头部有电平条 + 「常听中 · 直接说」状态。
2. **自动断句**：底噪自适应（先学环境 floor，再取 floor×2.2），静音 0.8s 判定一句说完；
   说满 15s 强制切，防止一口气把缓冲区撑爆。
3. **不自听**：`/api/voice` 返回后先按 TTS 音频时长等待播放结束，这段时间既不采音频也不判端点，
   否则会把自己的回答当成同事说话；同时开了 `echoCancellation`。
4. **自动接回**：5s 看门狗检查，只要「常听」还开着，采集中断了（休眠、切设备、AudioContext 被挂起）就自己接回去。
5. **随时能关**：「常听: 关」，或者按住「🎤 按住说话」手动说一句（手动优先）。

### 剧本接话：同事念上一句，小星接下一句（2026-11-13 新增）

语音输入先过一层 **`script_match.py`**：把 `script.json` 每条 cue 的 `keywords`（从同事原台词里提炼）
做关键词命中，再用相似度兜口音/错字，再加"顺序先验"。
命中就播**预渲染原声**，和点控制台按钮效果完全一样；对不上才交给意图引擎（查数、起 GPU 作业）。

`script.json` 已按 2026-11-13 新版 docx 重排为 **17 条**（旧的 19 条里有 2 条新版已删：
`好的，请提出需求。` 与配套的 `收到。`），17 条台词**逐字校验 17/17 一致**（`_tools/verify_verbatim.py`）。

## 九、已知限制（没做的，别当做了）

1. **浏览器真实麦克风还没在真机上按过一次**。整条 HTTP 链路是用 SAPI 合成音打通的
   （`_probe_asr\t1.wav`「让GPU跑一下训练」→ 起作业 → 2 轮跑完 → 语音追问「跑到哪一步了」答出真指标），
   但 getUserMedia 采集、权限弹窗、现场噪音在你这台机器上要**手动按一次「🎤 按住说话」确认**。
2. **还没填大模型 key**，现在走的是离线意图引擎（正则）。语义泛化有限，
   比如「把模型再练一练」这种说法能中，真正绕开剧本的闲聊它接不住。
   把 key 填进 `config/llm.json` 的 `api_key`（或设 `DEEPSEEK_API_KEY`）就切到真 LLM 通道，失败自动降级。
3. **SAPI 音色偏机器**。离线首选；有网时把 `config/llm.json` 里 `"tts": "edge"` 换成 edge-tts 更好听。
4. **ASR 会把「检出」听成「剪出」**，已用 11 条同音词表纠正；仍属词表兜底，不是模型改好了。
5. `ops_jobs/` 里每次作业都会留 `runs/weights/*.pt`（各 ~44MB），现场跑十几次记得清一次。
2. **2.5D 人像是照片，转不了身**。口型和眨眼是网格变形（拉伸 UV），不是真正的面部
   blendshape，所以侧脸/大角度转头做不了；正脸对话够用。
3. **3D 路线（Rocketbox / VRM）仍可用**，但 Rocketbox 21 个男性里**没有东亚面孔**，
   所以要"中国人 + 真 3D + 能说话"三者兼得，得另外找带 blendshape 的亚洲模型。
3. **未嵌入主系统窗口**。它是独立程序，通过只读库 + 8770 接口联动，不改 `new mcjc` 一行代码（产线在跑，红线不碰）。
4. **Agent 的四个交付任务是模板化的**。模板是真的能跑的代码，但不是针对你当场说的每一句需求实时生成——除非配了 LLM key。
5. **口型是能量驱动，不是音素驱动**。听感和观感够用，但不如逐音素对齐精细。
6. **8770 大屏服务当前没起**，所以数字人读的是库里数据，不是大屏接口。两者口径一致。
