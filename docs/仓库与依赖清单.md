## 四、新机器怎么把依赖拿齐

```
1) 数字人本体（本仓库）
      git clone https://gitee.com/shenfu1314/mcszr.git      # 或 https://github.com/shenfu820/mcszr
      cd mcszr && 一键配置环境.bat                          # 三个环境一条命令装完

2) 四屏舞台包：随本仓库走，不用单独 clone

3) 产线工程 new mcjc（只有代码；权重/检测库/输出要另拷）
      git clone https://gitee.com/shenfu1314/wood-testing.git <目标目录>
      然后把 config\paths.ini 的 PROD_ROOT 指到 <目标目录>

4) 对话中枢 angent：目前只有本地仓库（没有远端）
      - 在产线机上：整个目录拷过去即可（git=local 的仓库不带历史也行）
      - 或拿到远端地址后：git clone <地址> <PROD_ROOT 的父目录>\angent

5) 缺陷数据集：不建仓库，只登记路径
      把数据集放到任意目录，config\paths.ini 的 DATASET_ROOT= 指过去
      结构要求：images\{train,val} + labels\{train,val}（gpu_worker 按它生成 data.yaml）
```
