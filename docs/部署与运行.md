# 从零跑起来（clone 之后照做）

> 这套东西 = **小星（数字人形象 + 语音对话 + 真 GPU 调度 + 五块实屏）**。
> 仓库里只放**代码与必要素材**，大文件不进 git（见 `.gitignore`）。

## 0. 前置条件

| 东西 | 为什么需要 | 没有会怎样 |
|---|---|---|
| Windows 10/11 + Chrome/Edge | 形象窗口、五块屏都是浏览器 `--app` 窗口 | 起不来窗口 |
| Python 3.10（建议 3.10.21） | 主服务、Agent、TTS（纯标准库 + edge-tts） | 主服务起不来 |
| 一个装了 `funasr` 的 Python 3.11 环境 | 离线语音识别（Paraformer 中文） | 只能打字，不能说话 |
| 一个装了 `torch(CUDA)+ultralytics` 的 Python 3.10 环境 | 真 GPU 训练/评估/推理 | ⑤那块「调度 GPU」失效，其它照常 |
| 产线检测库 `wood_inspect.db`（只读） | 所有真实数字都来自它 | 查数类回答会报「库不存在」 |
| 板材缺陷数据集（可选） | 训练类作业要用 | 训练作业会明确报「数据集软链不存在」 |

> 本机实测环境：主服务 `E:\conda3\envs\yoloces` 建的独立 venv（3.10.21）；
> 语音 `E:\conda3\envs\voice`（3.11.18 + funasr 1.4.24）；GPU `E:\conda3\envs\yoloces`（torch 2.14.1+cu130）。

## 1. 装依赖

一条命令（新机器第一次）：

```bat
一键配置环境.bat
```

它会按「缺什么装什么」把**三个环境**都装好：

| 环境 | 装到哪 | 装什么 |
|---|---|---|
| `main` | `.venv` | `requirements.txt`（edge-tts、Pillow） |
| `asr` | `.venv-asr` | `requirements-asr.txt`（funasr + torch CPU） |
| `gpu` | `.venv-gpu` | torch（按有没有 NVIDIA 卡选 CUDA/CPU）+ `requirements-gpu.txt`（ultralytics） |

本机已有满足要求的环境（conda 的 `voice`、`yoloces` 之类）会**直接复用**，不重复下载；
装完逐个 `import` 校验，再把路径写回 `config\paths.ini`，最后建软链、修行尾、打体检表。

- 只看计划：`一键配置环境.bat --check`
- 只装一个：`--only asr`
- 弱网/国内机器（实测官方源可能只有几十 KB/s）：
  `一键配置环境.bat --index-url https://pypi.tuna.tsinghua.edu.cn/simple`
- 离线：`--offline`（先在有网机器上 `pip download -d wheels -r requirements*.txt`）

老名字 `一键部署_新电脑.bat` 保留，行为相同。

手工等价操作：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

:: 语音识别环境（独立环境，不是项目 .venv）
python -m venv .venv-asr
.venv-asr\Scripts\python.exe -m pip install -r requirements-asr.txt
```

> `requirements*.txt` 里**只能写 ASCII 注释**：pip 用系统 locale（中文 Windows 是 GBK）读这个文件，
> 注释里有中文就会 `UnicodeDecodeError: 'gbk' codec can't decode byte 0xad`。

## 2. 改路径（换机器才需要）

**只改 `config\paths.ini` 一个文件**，值留空 = 自动探测：

| 键 | 什么时候要填 | 本机实测值 |
|---|---|---|
| `PYTHON` | 想指定别的解释器（默认用 `.venv`） | 留空 |
| `ASR_PYTHON` | 装了 funasr 的那个环境 | `E:\conda3\envs\voice\python.exe`（探测自动找到） |
| `GPU_PYTHON` | 装了 torch(CUDA)+ultralytics 的那个环境 | `E:\conda3\envs\yoloces\python.exe`（探测自动找到） |
| `PROD_ROOT` | 产线工程 `new mcjc` 的位置 | `C:\Users\Administrator\Desktop\项目与竞赛\aa比赛项目\new mcjc` |
| `DATASET_ROOT` | 缺陷数据集根（含 `images/train`） | `F:\木材缺陷数据集6类3000+` |
| `BROWSER` | Chrome/Edge 非标准安装位置 | 留空（自动找） |
| `PORT` / `ASR_PORT` | 端口冲突时 | 8772 / 8773 |

环境变量优先于 ini：`DH_PY` / `DH_ASR_PY` / `DH_GPU_PY` / `DH_PROD` / `DH_DS` / `DH_BROWSER`。
代码里（`server/gpu_runner.py`、`server/gpu_worker.py`、`server/dh_paths.py`）已经不再写死任何绝对路径。

**为什么要软链**：Windows 把中文路径传给子进程会乱码，ultralytics 直接报 `images not found`。
所以按 ini 里的目标建三条 ASCII junction：`C:\dh_root`→本项目、`C:\dh_prod`→`new mcjc`、
`C:\dh_ds`→数据集（目标不存在时跳过，体检表标 `no-target`）。

建软链不需要管理员（`mklink /J` 是 junction，不是 symlink）。三处都会自动建：
`一键部署_新电脑.bat`、`启动数字人_语音版.bat`、以及 `python _tools\dh_env.py --check`
（想只看不动就加 `--no-fix`；单独修一次用 `--fix`）。指错方向的会报 `stale` 并被改回来。

## 4. 启动

```bat
启动数字人_语音版.bat            :: 正常启动（起服务 + 开窗口）
启动数字人_语音版.bat --check     :: 只体检不起服务，有 FAIL 退出码 1
启动数字人_语音版.bat --no-window :: 起服务不开窗口
启动数字人_语音版.bat --no-asr    :: 不拉语音识别，只打字
```

它做四件事：建软链 → 起 8773 语音识别（有 funasr 的那个环境，模型常驻约 15~75 秒）
→ 起 8772 主服务 → 开窗口。日志在 `logs\asr.log`、`logs\server.log`。

改动 record：**详细排障与错误对照表见 [跨机器部署.md](跨机器部署.md)**。

打开后的地址：

| 页面 | 地址 | 用途 |
|---|---|---|
| 小星 · 五屏 | `http://127.0.0.1:8772/xx/xiaoxing5.html` | 形象 + 五块实屏 + 麦克风 |
| 控制台 | `http://127.0.0.1:8772/console/` | 17 条台词点播 / 打字下令 / GPU 状态 |

## 5. 自检（30 秒）

```powershell
# ① 主服务
(Invoke-WebRequest http://127.0.0.1:8772/api/health).Content
# ② 语音识别
(Invoke-WebRequest http://127.0.0.1:8772/api/asr/health).Content      # 期望 state=ready
# ③ 五屏数据源
(Invoke-WebRequest http://127.0.0.1:8772/api/ops).Content             # GPU + 模型性能
(Invoke-WebRequest http://127.0.0.1:8772/api/stage).Content           # 自学习/检测/复核聚合
# ④ 起一个真 GPU 作业（约 60~90 秒，跑完自停）
(Invoke-WebRequest http://127.0.0.1:8772/api/job/start -Method POST -Body '{"mode":"train"}' -ContentType 'application/json').Content
```
